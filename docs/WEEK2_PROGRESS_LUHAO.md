## 后续接入

接入边界见 `frontend/src/data/week2.ts`。正式 C1–C3 契约确认后实现 `Week2DataSource` HTTP 适配器，再在 `frontend/src/main.ts` 的应用实例上 `provide(WEEK2_DATA_SOURCE, adapter)`；当前生产入口不注册数据源，不请求未定义接口。统计领域结构不是 C2 HTTP 响应约定，保存差异也不是 C3 请求体约定。

适配器须将服务端结果转换为领域数据，保留对象方法的 `this`，将读取/保存错误作为 rejected Promise 返回。参数读取须保留实际键和值；未知键只读、缺失阈值不补默认值。保存须等待服务器确认完成；随后页面重读服务端参数验证显示结果。适配器与真实接口交付后，还需补真实读写、权限/错误响应、统计口径和六页至少 16 项 E2E 验收。

浏览器组件验证：启动前端开发服务后访问 `/tests/week2-preview.html#/piles`。页面常驻“测试夹具、内存保存”提示；仅开发环境可用，不代表生产数据联调。
