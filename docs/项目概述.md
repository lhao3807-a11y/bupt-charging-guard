# 「桩」点北邮 —— 充电桩车位防占系统 · 项目概述

> 英文名：BUPT Charging Guard: EV Parking Anti-Occupation System
> 依托学院：北京邮电大学 信息与通信工程学院
> 全文约 840 字（要求区间 100–1000 字）

---

## 一、产品描述

「桩」点北邮——充电桩车位防占系统（BUPT Charging Guard），是一套面向高校校园的充电车位智能监管系统，依托北京邮电大学信息与通信工程学院建设，现为可完整演示的系统原型。

系统针对两类典型问题：燃油车违规占用充电车位，导致新能源车无法正常补能；新能源车充满后长时间不驶离，挤占充电资源。传统人工巡查效率低、发现不及时、难以留痕。系统通过摄像头采集图像，以 YOLOv8 检测车辆、以车牌识别获取号码并据车牌底色判定车型（绿牌新能源、蓝牌燃油），再结合模拟充电桩状态数据，由规则引擎输出燃油占位、异常占位、充满未移车、正常充电四类判定；命中违规即短信提醒车主并落库，供六页后台查询展示。技术栈为 FastAPI + Vue3 + MySQL 8，充电状态因运营商接口权限限制采用模拟，预留 OCPP 适配层。

## 二、用户群体

目标用户分三层：直接使用者是高校后勤与校园充电设施管理部门，即后台的实际操作者，此前只能靠人工巡查，需求最刚性；服务对象是校园新能源车主，接收移车提醒，体验取决于提醒是否及时；约束对象是燃油车及校内其他车辆使用者。推广层面，凡"有桩、有位、有占用矛盾"的园区、写字楼与公共停车场运营方均可复用。

## 三、项目愿景

短期把校园充电车位管理从"人管"推向"数管"，以"识别—判断—提醒"自动闭环提升车位周转率、降低巡查成本；中期形成一套低成本、可复制、可裁剪的智慧校园方案；长期沉淀"视觉识别 + 设备状态"融合判断的方法，用于更多需要区分合法与违规占用的场景。结题计划交付系统原型、技术报告与用户手册，并申请软件著作权。

## 四、竞争对手

现有方案分三类，各有短板：一是充电运营类 App，侧重设备监测、找桩与计费，基本不介入车位占用监管，无法识别并追责占位车辆；二是以车牌识别为核心的智慧停车系统，能识别车牌并完成道闸计费，却拿不到充电状态，因而无法区分"正在充电"与"充满未移车"，易误判漏判；三是人工巡查加视频监控，成本高、时效差、缺少结构化记录，难以支撑统计与考核。

本项目的差异点在于：判定违规必需的"充电状态"这一维度，只有与视觉识别联合才可获得，二者融合才能准确识别"充满未移车"这类既非占位违规、又确实浪费资源的中间状态，从而与同类方案形成明确区隔。
