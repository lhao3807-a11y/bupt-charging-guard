## 2. 截图方法（可复现）

**关键点：截图必须来自真实运行的前后端，且数据要由系统自己产生**（不能手改数据库或前端 mock）。

### 2.1 启动服务

```bash
# ① 后端（开发期 SQLite，启动时自动建表 + 灌种子）
cd backend
<venv>/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000

# ② 前端
cd frontend
npm run dev          # http://localhost:5173
```

> ⚠️ Vite 在部分 Windows 环境监听的是 **IPv6 `[::1]:5173`**，用 `http://127.0.0.1:5173`
> 会连不上，请用 `http://localhost:5173`。

### 2.2 产生演示数据（走真实闭环）

后端种子**不含违规记录**（`occupation_record` 为空），需通过契约端点产生。
按 `CONTRACT.md` §6.1/§6.2，用 `algo/samples/labels/` 的标注帧驱动：

```bash
# 对每个标注帧：recognize → judge（命中即落库）
POST /api/recognize  {"frame_ref": "001.jpg"}      # → RecognitionResult
POST /api/judge      <上一步返回>                   # → ViolationRecord（规则 ④ 返回 null）
```

一次典型结果（与本仓库 `algo/samples/labels/` 的 4 个帧对应）：

| 帧 | 车牌 | 车型 | 判定结果 |
|---|---|---|---|
| `001.jpg` | 京AD12345 | 新能源 | **`null`** —— 规则 ④ 正常充电，不落库（契约明确行为） |
| `002.jpg` | 京A88888 | 燃油 | `rule_hit = 1` 燃油车占位 |
| `003.jpg` | 京AD24680 | 新能源 | `rule_hit = 2` 异常占位 |
| `004.jpg` | 京AD67890 | 新能源 | `rule_hit = 3` 充满未移车 |

再调 `POST /api/notify {"id": 1, "notify_status": "已提醒"}` 让部分记录进入已提醒状态，
使「提醒状态」列有区分度（未提醒黄 / 已提醒绿）。

### 2.3 截图

```bash
agent-browser open http://localhost:5173/vehicle
agent-browser set viewport 1600 1000
agent-browser wait 2500
agent-browser screenshot docs/design/demo/screenshots/01-vehicle.png
# 其余 5 页同理；全部完成后
agent-browser close --all
```

| 页面 | 路由 | 目标文件 |
|---|---|---|
| 第 1 页 车辆信息管理 | `/vehicle` | `01-vehicle.png` |
| 第 2 页 违规记录查询 | `/records` | `02-records.png` |
| 第 3 页 充电状态展示 | `/piles` | `03-piles.png` |
| 第 4 页 报警统计 | `/statistics` | `04-statistics.png` |
| 第 5 页 系统参数配置 | `/config` | `05-config.png` |
| 第 6 页 实时识别预览 | `/preview` | `06-preview.png` |

视口统一 **1600×1000**（内容区最大宽 `--layout-max-width` 1440px，两侧留白对称），
`devicePixelRatio` 建议 ≥2（高分屏截图可直接进 PPT）。

### 2.4 美化要求

统一设备框（1px `--border-base` 描边 + `--radius-md` 圆角）、窗口标题条（左侧三色圆点 + 页面标题）、
必要时裁掉浏览器滚动条。**不要加渐变或投影滤镜** —— 与系统本身的克制风格一致。
