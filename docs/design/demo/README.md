## 2. 截图方法（可复现）

**关键点：截图必须来自真实运行的前后端，且数据要由系统自己产生**（不能手改数据库或前端 mock）。

### 2.1 启动服务

```bash
# ① 后端（开发期 SQLite，启动时自动建表 + 灌种子）
cd backend
<venv>/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000

# ② 前端
cd frontend
npm run dev          # http://localhost:5173
```

> ⚠️ Vite 在部分 Windows 环境监听的是 **IPv6 `[::1]:5173`**，用 `http://127.0.0.1:5173`
> 会连不上，请用 `http://localhost:5173`。

### 2.2 产生演示数据（走真实闭环）

后端种子**不含违规记录**（`occupation_record` 为空），需通过契约端点产生。
按 `CONTRACT.md` §6.1/§6.2，用 `algo/samples/labels/` 的标注帧驱动：

```bash
# 对每个标注帧：recognize → judge（命中即落库）
POST /api/recognize  {"frame_ref": "001.jpg"}      # → RecognitionResult
POST /api/judge      <上一步返回>                   # → ViolationRecord（规则 ④ 返回 null）
```

一次典型结果（与本仓库 `algo/samples/labels/` 的 4 个帧对应）：

| 帧 | 车牌 | 车型 | 判定结果 |
|---|---|---|---|
| `001.jpg` | 京AD12345 | 新能源 | **`null`** —— 规则 ④ 正常充电，不落库（契约明确行为） |
| `002.jpg` | 京A88888 | 燃油 | `rule_hit = 1` 燃油车占位 |
| `003.jpg` | 京AD24680 | 新能源 | `rule_hit = 2` 异常占位 |
| `004.jpg` | 京AD67890 | 新能源 | `rule_hit = 3` 充满未移车 |

再调 `POST /api/notify {"id": 1, "notify_status": "已提醒"}` 让部分记录进入已提醒状态，
使「提醒状态」列有区分度（未提醒黄 / 已提醒绿）。

### 2.3 截图 + 美化（一条命令）

第 2 周踩过的坑：`agent-browser` 首次拉 Chromium 卡死 16 分钟，**不靠谱**；
而本机装了 Edge（Chromium 内核），它的无头截图参数与 Chrome 完全一致。于是把
「拍摄 → 套设备框」写成了脚本，颜色从 `tokens.css` **读**而不是抄：

```bash
python docs/design/tools/demo_screenshots.py              # 拍摄 + 美化
python docs/design/tools/demo_screenshots.py --frame-only # 只重做美化（改了框子时用）
python docs/design/tools/demo_screenshots.py --shoot-only # 只重拍（页面改了时用）
```

产物：

| 路径 | 内容 |
|---|---|
| `screenshots/raw/*.png` | **原始截图**（未加工，视口 1600×880），保留它是为了「证明这是真实页面」 |
| `screenshots/*-framed.png` | **美化版**：统一设备框 + 窗口标题条 + 图注，直接进 PPT |

脚本里 `PAGES` 是唯一要维护的地方 —— 第 3/4/5/6 页实现后，往那张表里加一行即可，不必改逻辑。
拍摄参数：无头 Chromium、视口 **1600×880**、`--virtual-time-budget=8000`。

> ⚠️ **`--virtual-time-budget` 不能省**：SPA 的懒加载路由组件在截图那一刻可能还没挂载，
> 少了它拍出来是「骨架在、内容区空白」。第 2 周实拍验证过，不是理论风险。

> ⚠️ **`raw/` 是交付物的一部分，不是临时文件。** 任务书对 6.10 的硬要求是「截图须真实页面，
> **不许用线框冒充**」，这句话已落成机械断言（`check_tokens.py` [6] 项）：每张 `*-framed.png`
> 必须在 `raw/` 有同名原件、美化版尺寸必须大于原件、同批原件视口必须一致。
> 也就是说**删掉 `raw/` 会让设计校验直接变红** —— 这是有意的：没有原件就证明不了「这是实拍的」。

### 2.4 美化规格（已实现，见 `tools/demo_screenshots.py`）

| 元素 | 规格 | 取值来源 |
|---|---|---|
| 画布底色 | `--bg-page`，四周留白 40px | `tokens.css` |
| 窗口本体 | `--bg-container` 底 + 1px `--border-base` 描边 + 10px 圆角 | 同上 |
| 投影 | 高斯模糊 8px、`rgba(31,35,41,0.18)` —— 克制的一层，不加渐变/滤镜 | 同上 |
| 标题条 | 高 36px、`--fill-light` 底、底部 1px `--border-base` | 同上 |
| 窗口标题 | 页面名 · 桩点北邮防占系统，`--text-secondary` 13px，左对齐 | 同上 |
| 圆点 | 3 个 10px 圆，**中性色 `--border-strong`** | 同上 |
| 图注 | 左：序号 + 页面名（`--text-primary`）；右：品牌 + 「演示原型」（`--text-tertiary`） | 同上 |

> **圆点为什么不用红黄绿**：本项目的红/橙/黄/绿是「违规严重度」的语义色
> （`rule_hit` 1红/2橙/3黄/0绿，跨页必须同序）。拿语义色做装饰，
> 等于在一张图里塞两套色义，答辩时容易被问「这个绿灯是什么意思」。

## 4. 数据脱敏口径

| 字段 | 口径 | 依据 |
|---|---|---|
| **手机号** | **必须脱敏**：`138****6621`（前 3 + `****` + 后 4） | 任务书 6.10 确认口径；前端 `utils/format.ts` 的 `maskPhone` 已实现 |
| **车牌** | ⚠️ **暂不脱敏**（完整显示） | 任务书要求「先问吕」。车牌是本系统的业务主键，脱敏后无法与「充电桩绑定」「识别结果」互相对照。**待回签**，见 `copywriting.md` §7.1 |
| 车主姓名 | 保留（演示种子数据为虚构姓名） | — |
| 桩 ID | 保留（`PILE-001` 等，非敏感） | — |

> 截图前请确认页面上**没有真实个人信息**：当前种子数据（`backend/app/models.py` 的 `SEED_VEHICLES`）
> 与标注帧（`algo/samples/labels/*.json`）均为虚构数据，可安全用于答辩。
