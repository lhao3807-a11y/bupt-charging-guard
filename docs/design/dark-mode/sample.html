本方案的关键决策（评审时看这四条就够）

  • 主按钮反相：深色下主色 --brand-primary 提亮到 #5B9BFF，实心块变亮， 因此按钮文字走 --text-inverse（此时为深色 #14161A）—— 与浅色模式的白字相反。 照抄浅色会让主按钮白字掉到 2.77:1。
  • 层级靠描边不靠底差：三档底 #0F1115 / #1B1F25 / #262A31 之间仅 1.14–1.15:1， 容器边界由 --border-base 承担。这是深色模式的通用做法，不要为了"看得见层级"把底压成纯黑。
  • 状态色 -solid 仍只做填充：深色下 -solid 档亮度提升（3.6–7.8:1 对卡片底）， 但语义分工不变 —— 白底/深底上的文字与图形一律走 -text 档。
  • 份额序列不借违规色：环形图用主色梯度，不用红橙黄绿（同 component-inventory.md §3.1 ②）。
