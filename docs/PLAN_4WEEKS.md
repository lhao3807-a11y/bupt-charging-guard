## 6. 每日 / 每周纪律

**每日**
- 开工先 `git pull --rebase`，收工必 commit（信息格式 `模块: 简述`）。
- 交付前跑：`pytest backend/tests -q` + `ruff check backend scripts` + `python docs/design/tools/check_tokens.py`，**全绿才 push**。

**每周五**
- 三人各 5 分钟同步：**已完成 / 卡点 / 下周提供什么**。
- 吕浩统一合入，确认 `main` 上测试全过。
- 契约如有改动，**先改 `CONTRACT.md` → @全员 + 升版本号**，再动代码。

**红线（不可越）**
- 阈值一律从 `system_config` 读，**严禁硬编码**（契约 §7）。
- 页面里**不出现裸色值**，一律 `var(--token)`。
- 表格列以契约字段为准，**不自造字段、不自造枚举**（页面增删须先改契约 §1.1）。
- 沙箱内跑本地 HTTP 服务前先 `os.environ["NO_PROXY"]="*"`（第 0 天踩过的坑）。
