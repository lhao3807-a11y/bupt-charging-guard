# M2/M3 实拍训练与验证计划

**目标：** 完成用户批准的两模型方案，报告独立实拍 val 指标与 RecognitionResult 输出，不设额外准确率门槛。

**设计：** 车辆检测采用网络充电实拍及人工车辆框；车牌检测采用既有中国车牌实拍中来源与许可完整的子集，沿用已人工标注的车牌框、号码及车型。两个数据集单独划分、训练和验证。充电会话记录不在本阶段范围内。

**技术：** YOLOv8n、PyTorch、HyperLPR3、OpenCV、Pydantic。独立 `.venv-algo`；模型在忽略目录保留并记录 SHA-256；日志和指标入库。

- [x] 恢复算法环境，记录实际依赖与 CPU/CUDA 可用性。
- [x] 写数据准备测试：排除缺来源/许可图片，独立划分，无图像重复，合法目标框。
- [x] 人工检查充电照片并标车辆框；准备有来源的车牌子集，输出可复现数据清单。
- [x] 写训练设备与 OCR 多车匹配回归测试，运行失败后修复需要的代码。
- [x] 微调两个模型，保存权重、训练参数、日志和哈希；报告 val mAP50 与 mAP50-95。
- [x] 实拍 OCR/车型评估，保留逐图预测、失败样例和 RecognitionResult 契约验证。
- [x] 更新运行及验收文档，运行算法和相关后端回归、Ruff，提交所有任务变更。
