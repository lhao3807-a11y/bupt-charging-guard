# 吕浩第二周接口切换实施计划

依据：PLAN_4WEEKS §3.1、CONTRACT v1.4 §6.4/§6.6；用户授权按可完成范围推进。

## 设计与范围

保持现有 Vue / Pinia / Axios 分层与设计令牌。记录和车辆列表均由服务端筛选、分页；查询表单与已提交条件分离，翻页及刷新沿用已提交条件。日期原样以 YYYY-MM-DD 传递，由后端包含结束日全日；规则 0 不得被空值处理丢弃。请求竞态只接纳最后一次结果。

车辆新增、更新、删除等待 API 成功；失败保留表单及列表，不再使用 localStorage 或浏览器种子。成功后重新读取列表，删除末页最后一条时回退有效页。兼容后端 owner/phone 为 null。
