## 建议返工顺序

1. **先定契约和测试真值表**：完成 T1、T6 的状态/字段/阈值口径并留确认记录；同步契约及前端类型，避免前后端各自定义状态。
2. **实现存储、发送和幂等**：完成 T2、T4 的模型/schema/迁移、沙箱服务、尝试持久化、失败重试及并发保护。先通过 A05、A07，再接自动触发。
3. **接通自动链路**：完成 T3，让实拍帧和模拟状态进入同一判定/提醒服务；提供只读结果查询，验证坏帧或无牌时错误可见且不伪造结果。
4. **补场景与适配边界**：完成 T5 四个确定性场景，覆盖阈值前、相等、超过的边界；证明燃油车模拟不会进入充电状态。
5. **在 MySQL 和可复现环境验收**：完成 T7；记录启动命令、提交号、配置模式、测试结果、请求响应、记录 ID、重启前后状态。SQLite/stub 的通过结果不能替代 MySQL/real 模式对应证据。
6. **最后回填验收表**：按[计划中的 A01–A16](WEEK3_PLAN.md#5-验收矩阵)逐项填写通过/失败/未测、证据路径和责任人；未通过项保留明确阻塞原因。A17 单独标注，可不做。
