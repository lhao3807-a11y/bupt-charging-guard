# M3 可追溯网络中国车牌子集

从旧 `dataset_web` 174 张中筛出 94 张来源页、许可和作者完整的照片，经人工逐张查看号牌裁剪图后保留普通蓝/绿牌 93 张（75 train / 18 val）。排除一张警用号牌，并修正 11 张旧号码错配/O 与 0 等错误，详见 `review.json`；旧目录历史指标保持原样。

val 含新能源 8 张、燃油 10 张。train/val 按摄影作者分组，牌号亦无跨划分重复；同一作者的照片全部放在同一侧。源图像文件复用 `dataset_web`，来源、许可、框、号码、车型、固定划分及图像 SHA-256 在 `manifest.json`。许可为 CC0 / CC BY-SA 4.0，保留原始作者和 Commons 来源页。这里只验证可见中国车牌及绿蓝牌车型规则；不推断桩状态和充电会话。

运行 `algo/tools/prepare_week2.py` 后在 `.tmp-m2/data/plate/` 生成 YOLO 标签和图片。训练只使用这个来源完整子集，不混入来源记录缺失的 80 张旧网络照片、合成图或未提供的 CCPD 本地数据。18 张 val 的逐图识别输出、失败样例和契约校验见 [验收凭据](../../docs/acceptance/algo/week2-web/README.md)。
