## 诚实的局限说明（答辩/验收必须讲清楚）

1. **这不是校园实拍**。场景以街景/公共停车场为主，绝大多数画面**没有充电桩上下文**。
   `meta.json` 的 `scene` 字段按画面实际内容如实打标：
   - `充电位-充电中(可见充电枪/桩)`：仅个位数（如 0086，绿牌车正插枪充电）；
   - `充电位-燃油占位`：仅 0027 一张；
   - `停泊-新能源 / 停泊-燃油`：其余全部（无充电位上下文，但车牌检测/识别管线完全适用）。
   计划 §2.2/§5.3 的「四类各 ≥30」无法用网络照片诚实达成 —— **充电位上下文样本仍需校园实拍补齐**
   （备选①）。四类场景的时间性区分（充电中/已充满/久停）本就不由单帧图像承担，而由
   规则引擎按时间+桩状态判定；数据集为检测/识别管线提供的是真实车牌素材。
2. **隐私**：照片中的车牌是真实号牌，均来自公开发布的照片。若对外展示请自行打码；
   训练用途的原始图按许可要求保留署名（见 `licenses.csv`）。
3. **许可**：逐张记录在 `licenses.csv`（来源页/协议/作者）；ND 协议在采集阶段已剔除
   （微调属于衍生使用）。

## 标注口径

- YOLO 单类 `plate`（id=0），与 `dataset_real` 一致；标签由 train_real 权重
  （CCPD val mAP50 0.994）预标 + **人工逐张目检**（联系表渲染核验框贴合与牌色）。
- `meta.json` 的 `bbox_plate=[x1,y1,x2,y2]`；`plate` 为人工核验的牌号（非 OCR 原样）。
- train/val 按**牌号哈希**切分（约 25% val）：同车多角度必落同侧，避免指标虚高。

## 与 CCPD 实拍集的关系

微调用 `data_real_web.yaml`：train = `dataset_real` 640 + `dataset_web` 138；
val = `dataset_real` 160 + `dataset_web` 36。CCPD 提供"规整近距离"样本，
网络实拍提供"真实街景/多角度/多光照"多样性；二者互补，指标分开报告
（`docs/acceptance/algo/06-eval-real-full.json` 与 `07-eval-web.json`）。
