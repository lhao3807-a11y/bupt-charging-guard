# M2 网络充电场景车辆标注集

使用 `dataset_charging_photos` 中人工检查的 97 张不同照片：80 train / 17 val，共 62 个车辆框，50 张为空充电位/充电设备等负样本。图片复用原目录；`annotations.json` 是人工绘制的归一化可见范围 xyxy 框，`manifest.json` 包含来源、许可、图像 SHA-256、尺寸、像素框和固定划分。

标注目标为轿车/厢式车，包含部分出画、被桩或人遮挡的车辆。标注框包围可见车身；占图像面积不足 5% 的远处交通不标。该范围限制也适用于指标解读，不能据此声称远距离小车辆检测已经验收。未标充电枪状态、停留时长或充满状态。

train/val 按摄影作者分组，同一作者的近似拍摄角度不会跨划分；val 有 17 张照片、14 个框，其中 9 张有目标车辆、8 张负样本。样本量较小，是当前原型验证集。人工标注工具为照片联系表与逐图可见范围核对；标签由人工目视给出，未把模型预测当真值。

val 中两处面积小于 5% 的可见远车另记在 `ignored_small_vehicles`，不参与训练目标标注。固定阈值评估将与这些区域 IoU≥0.5 的范围外预测单列 ignored；原始 Ultralytics mAP 无忽略区域支持，保留该保守偏差并在报告中说明。

在仓库根目录运行 `.venv-algo/Scripts/python.exe algo/tools/prepare_week2.py`，生成忽略目录 `.tmp-m2/data/vehicle/` 的 YOLO 图片、标签与机器路径配置。生成操作会清理并重建该临时数据目录。训练与独立验证步骤及实际指标见 [验收凭据](../../docs/acceptance/algo/week2-web/README.md)。
